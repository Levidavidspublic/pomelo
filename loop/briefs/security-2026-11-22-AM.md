- HTTP. `src/local/start.ts` always passes `local`, and every `createApp` caller found does too, so the server listens on `127.0.0.1` (`src/app.ts:7557`). `localOnly` (`src/app.ts:7782`) requires a loopback `Host` and Friday's own `Origin`.
